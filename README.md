# Writewise — ฝึกคิดก่อนเขียน IELTS

เว็บฝึก IELTS Writing Task 2 สำหรับผู้เริ่มต้น อธิบายภาษาไทย มีโหมดกลางคืนและตัวอักษรปรับขนาดได้ ออกแบบให้ใช้งานบนแท็บเล็ตและคอมพิวเตอร์

## เริ่มใช้

ดาวน์โหลด `index.html` แล้วเปิดในเบราว์เซอร์ที่รัน HTML/JavaScript ได้ ไม่มีขั้นตอนติดตั้งและไม่ต้องใช้อินเทอร์เน็ตสำหรับบทเรียน บน iPad แนะนำเปิดผ่านลิงก์ GitHub Pages ใน Safari เพราะตัวอย่างไฟล์ในแอป Files อาจไม่รันปุ่ม

## เปิดเว็บด้วย GitHub Pages

เจ้าของคลังเปิด **Settings → Pages → Build and deployment → Deploy from a branch** แล้วเลือก **main / (root)** และกด **Save** รอ GitHub แจ้งว่าพร้อมใช้งาน แล้วใช้ลิงก์ที่ GitHub แสดงในหน้า Pages

หากเปิด Pages ของคลัง `exclusive4864/ccbbnn` ที่ branch หลักสำเร็จ ที่อยู่โดยปกติคือ `https://exclusive4864.github.io/ccbbnn/` โปรดตรวจสถานะจริงก่อนแจก ลิงก์นี้ยังไม่ใช่การยืนยันว่าเปิดบริการแล้ว

สามารถฝากไฟล์ index.html บนบริการ static hosting อื่นได้เช่นกัน ไม่ต้องมีฐานข้อมูลหรือเซิร์ฟเวอร์ประมวลผล

## มีอะไรบ้าง

- บทความเต็ม 9 ชิ้น: 3 โจทย์ × ระดับเป้าหมาย 7, 8, 9
- Positive/negative, discuss both views และ advantages outweigh disadvantages
- คำอธิบายไทยรายย่อหน้า ข้อดี ข้อจำกัด และแนวทางฝึกต่อของทุกตัวอย่าง
- พื้นฐานประโยค วิธีขยายเหตุผล และโครงอ่านคำสั่ง 7 แบบ
- Collocation 24 ชุด พร้อมบัตรคำ แบบเติมคำ และพื้นที่แต่งประโยค
- ห้องเขียน เก็บร่างในเบราว์เซอร์ นับคำโดยประมาณ จับเวลา 40 นาที และส่งออก .txt
- โจทย์ใหม่สำหรับย้ายทักษะ และแผนฝึก 28 วัน
- โหมดสี 3 แบบ ขนาดตัวอักษร 16–26 พิกเซล และหน้าจอปรับตามความกว้าง

## กระบวนการฝึก

1. อ่านคำสั่งและบอกว่าต้องตอบกี่เรื่อง
2. คิดจุดยืน เหตุผล กลไก และตัวอย่างเป็นไทยก่อน
3. อ่านเป้าหมาย 7 ให้เข้าใจ แล้วเทียบ 8 และ 9 ว่าเหตุผลแม่นขึ้นอย่างไร
4. ปิดเฉลยและเขียนใหม่ด้วยภาษาที่ควบคุมได้
5. เปลี่ยนหัวข้อ ทบทวนคำและข้อผิดพลาดในวันถัดไป

ไม่ต้องรีบเลียนแบบศัพท์หรือความยาวประโยคของเป้าหมาย 9 และไม่มี collocation ที่ต้องใช้ทุกข้อสอบ

## คะแนนและขอบเขต

ตัวอย่างทั้งหมดแต่งใหม่เพื่อการเรียน ป้าย Band เป็นระดับเป้าหมายเชิงการสอน ไม่ได้ผ่านการรับรองจากผู้ตรวจ IELTS ไม่ใช่ข้อสอบจริง และไม่รับประกันผลสอบ โปรแกรมไม่ตรวจไวยากรณ์หรือให้คะแนน Band อัตโนมัติ ปุ่มตรวจความพร้อมตรวจเพียงจำนวนคำและการแบ่งย่อหน้า ยังไม่มีบทเรียน Task 1

เกณฑ์อ้างอิง:

- [IELTS Writing Band Descriptors](https://ielts.org/cdn/ielts-guides/ielts-writing-band-descriptors.pdf)
- [IELTS Academic Writing format](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-writing)

ตรวจข้อมูล 9 กันยายน 2026 โปรแกรมไม่เกี่ยวข้องอย่างเป็นทางการกับ IELTS

## ข้อมูลส่วนตัวและการสำรอง

ร่าง แผนเขียน ประโยคบัตรคำ และรายการที่ทำแล้วเก็บด้วย localStorage เฉพาะเบราว์เซอร์และที่อยู่เว็บนั้น ไม่มีการส่งงานเขียนไปเซิร์ฟเวอร์จากโปรแกรมนี้ ไม่มี analytics หรือสคริปต์ภายนอก บริการที่ฝากเว็บอาจมีบันทึกการเข้าถึงตามนโยบายของบริการนั้น

โหมดส่วนตัว การล้างข้อมูล หรือการย้ายที่อยู่เว็บอาจทำให้งานเดิมไม่ปรากฏ ใช้ปุ่มดาวน์โหลดงาน .txt เพื่อสำรองงาน ไม่ควรพึ่งการเก็บในเบราว์เซอร์เพียงอย่างเดียว ตัวจับเวลาไม่เก็บสถานะเมื่อโหลดหน้าใหม่

## การตรวจสอบฉบับนี้

ตรวจรูปแบบ JavaScript และทดสอบตรรกะการแสดงทั้ง 7 หน้า การสลับตัวอย่าง ร่างและการบันทึกชั่วคราว การนับคำ ตัวควบคุมเวลา และบัตรคำด้วยชุดตรวจในเครื่อง บทความเต็มทุกชิ้นมีอย่างน้อย 250 คำตามตัวนับของโปรแกรม ยังไม่ได้ทดสอบกับ iPad เครื่องจริงหรือยืนยันภาพหน้าจอใน Safari

## การนำไปใช้ต่อ

ผู้รับไฟล์สามารถเปิดใช้และแบ่งไฟล์นี้ให้ผู้อื่นได้ เนื้อหาเกณฑ์ทางการและเครื่องหมาย IELTS เป็นของเจ้าของสิทธิ์ที่เกี่ยวข้อง ควรเก็บคำอธิบายเรื่องระดับเป้าหมายและแหล่งอ้างอิงไว้เมื่อดัดแปลงบทเรียน
